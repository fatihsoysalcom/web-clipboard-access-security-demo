# Web Clipboard Access Security Demo

This example demonstrates web browser security restrictions on clipboard access. It shows how direct, unprompted access to the clipboard is blocked for security and privacy reasons, while user-initiated copy and paste operations using the `navigator.clipboard` API are permitted, often after a user permission prompt. The demo highlights the difference between secure, user-driven interactions and attempts at unauthorized access.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in a modern web browser (e.g., Chrome, Firefox, Edge).
3. Observe the console output for direct access attempts and interact with the buttons to see user-initiated clipboard operations.
